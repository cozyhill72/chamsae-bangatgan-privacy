1. 운영 주체와 문의

앱 이름은 참새방앗간, 개발·운영 주체 및 개인정보 관련 문의 담당은 제이랜서(J Lancer)입니다.

문의 이메일: cozyhill@jlancer.net

문의 시 회신 이메일 주소와 이용자가 보내는 문의 내용·첨부파일을 문의 확인 및 답변 목적으로 처리합니다. 문의 목적이 달성되면 지체 없이 삭제하되, 법령상 보관 의무가 있는 경우에는 그에 따른 기간 동안 보관합니다. 문의에 실제 쇼핑 목록이나 개인정보가 포함된 JSON·기기 로그를 꼭 필요하지 않은 한 첨부하지 마세요. 앱에 문의 자동 전송 기능은 없습니다.

2. 기기에 저장하는 정보와 이용 목적

앱은 쇼핑 목록의 표시·정렬·수정·구매 체크·장소별 분류 및 재실행 후 복구를 위해 다음 정보를 저장합니다.

  • 이용자가 입력한 상품명, 장소 이름, 수량, 구매 완료 여부
  • 목록 항목 구분용 식별값과 항목 생성 시각
  • 이용자가 관리하는 장소 목록 및 저장 형식 버전

항목 식별값은 목록 항목을 구분하기 위한 값이며 광고 식별자나 기기 고유번호가 아닙니다. 장소는 이용자가 입력하는 분류 이름으로, GPS 위치를 수집하는 기능이 아닙니다. 이름·연락처·건강 관련 내용 등 개인정보를 상품명이나 장소에 입력하면 그 내용도 목록에 포함될 수 있으므로 불필요한 개인정보를 입력하지 마세요.

Android는 Capacitor Preferences를 통해 앱 전용 저장 공간의 SharedPreferences에 저장합니다. 브라우저 실행은 해당 사이트·브라우저 프로필의 localStorage를 사용합니다. 앱 저장 키는 signa_chamsae_v11이며 구버전 로컬 데이터가 있으면 읽어 이전하는 코드가 있습니다. 앱은 목록을 별도로 암호화하는 기능을 제공하지 않습니다. 기기 및 운영체제의 잠금·저장소 보호 기능도 함께 사용하세요.

Android 앱과 브라우저, 서로 다른 브라우저·프로필·기기, 별도 패키지의 이전용 앱은 저장 공간이 독립적입니다. 자동 계정 연동이나 동기화는 하지 않습니다. 비공개 브라우징·저장 공간 부족·브라우저 정리 기능 등으로 웹 데이터가 사라질 수 있으므로 필요한 목록은 외부 백업을 보관하세요.

3. JSON 백업·복원과 이용자가 선택하는 외부 전송

설정 → 백업 저장은 앱 이름, 백업 형식 버전, 내보낸 시각, 전체 상품 항목과 장소 목록을 평문 JSON 파일로 만듭니다. 완료 항목도 백업에 포함됩니다.

  • Android: 먼저 앱의 캐시 영역에 파일을 만든 후 Android 공유창을 엽니다. 이용자가 선택한 파일 저장 앱·이메일·메신저·클라우드 등으로 파일이 전달될 수 있습니다. FileProvider를 통해 선택된 수신 앱에 파일을 읽을 수 있는 임시 접근 권한을 부여합니다.
  • 브라우저: JSON을 다운로드 파일로 제공합니다. 실제 저장 위치와 보관 방식은 브라우저 및 이용자의 선택에 따릅니다.

백업은 암호화·비밀번호 보호되지 않습니다. 다른 사람에게 보내거나 클라우드에 저장하면 파일 안의 목록도 그 상대방·서비스에 전달될 수 있습니다. 개발자가 백업 사본을 자동으로 받거나 목록 저장 서버에 자동 업로드하는 기능은 없습니다. 이용자가 선택한 외부 서비스의 처리·보관·국외 전송 여부는 해당 서비스의 정책과 이용자 설정에 따릅니다.

공유창 표시 또는 “백업 파일을 준비했어” 알림만으로 외부 저장 완료를 보장하지 않습니다. 실제 파일 존재를 확인하고, 같은 날짜의 기본 파일명이 같을 수 있으므로 기존 백업을 덮어쓰지 않도록 이름을 구분하세요. 캐시는 운영체제가 정리할 수 있습니다.

설정 → 백업 복원은 이용자가 선택한 파일을 읽어 JSON 구조·항목 형식·크기 등을 검사합니다. 현재 구현은 2,000,000바이트 초과 파일을 거부하며, 정상 파일은 교체 확인 후 현재 상품·장소 목록 전체를 교체합니다. 병합이나 개발자 서버로의 업로드가 아닙니다. 잘못된 파일 또는 교체 취소 시에는 복원을 진행하지 않습니다.

복원 전 현재 목록도 별도 백업하세요. 저장 실패 시 화면의 메모리 상태와 디스크 데이터가 다를 수 있으며 자동 롤백이나 모든 장애에서의 원자적 교체를 보장하지 않습니다. 외부 원본 백업을 유지하고 오류가 있으면 계속 편집하지 마세요.

4. Android 시스템 백업·기기 이전

현재 Android 설정은 android:allowBackup="true"이며 앱 전용 데이터에 대한 별도 백업 제외 규칙은 설정되어 있지 않습니다. 따라서 기기·OS 버전·Google 또는 제조사 백업 설정에 따라 앱 데이터가 운영체제의 클라우드 백업이나 기기 간 이전에 포함될 수 있습니다. 이는 개발자가 운영하는 목록 서버로 전송하는 기능과는 다릅니다.

시스템 백업 이용·삭제는 Android/Google/기기 제조사의 설정과 정책을 확인하세요. 앱 데이터 삭제나 앱 제거만으로 이미 만들어진 시스템 백업·기기 이전 사본까지 삭제된다고 보장하지 않습니다. 백업에서 데이터가 다시 복원될 수도 있습니다.

5. 보관 기간과 데이터 삭제 방법

개발자는 쇼핑 목록의 중앙 사본을 보유하지 않습니다. 로컬 데이터는 이용자가 삭제하거나 앱·브라우저·OS의 데이터 정리로 제거될 때까지 기기에 남습니다.

  • 개별 상품: 목록 항목의 삭제(×) 버튼을 누르고 확인합니다.
  • 완료 상품: 목록 하단 목록 정리 → 완료 정리에서 확인 후 삭제합니다. 완료 보기는 숨김/표시 기능이므로 숨기는 것만으로 삭제되지 않습니다.
  • 장소: 장소 관리에서 해당 장소의 삭제 버튼을 누릅니다. 사용 중인 장소를 삭제하면 확인 후 그 장소의 상품은 미지정으로 바뀌며 상품 자체가 삭제되지는 않습니다.
  • Android 전체 로컬 초기화: 기기 설정의 앱 → 참새방앗간 → 저장공간 → 데이터 삭제/저장공간 비우기를 이용할 수 있습니다. 기기에 따라 명칭이 다르며, 앱 제거 시에도 앱 전용 데이터가 제거될 수 있습니다. 필요한 백업을 먼저 보관하세요. 앱 내부에는 별도의 “모든 데이터 삭제” 버튼이 없습니다.
  • 브라우저: 해당 사이트의 사이트 데이터·로컬 저장소를 삭제합니다. 단순 새로고침이나 캐시만 삭제하는 동작은 목록 삭제와 다릅니다. 이전용 앱이나 다른 브라우저의 데이터는 별도로 관리합니다.
  • 외부 사본: 다운로드한 JSON, 공유 수신 앱의 파일·메시지, 클라우드 및 시스템 백업은 각각의 보관 위치에서 별도로 삭제해야 합니다. 휴지통·동기화 사본도 확인하세요.

앱의 논리적 삭제를 모든 저장장치의 물리적 복구 불가 삭제로 보장하지는 않습니다. 개발자는 이용자 기기의 로컬 목록을 원격 열람·삭제·복구할 수 없습니다. 열람·정정·삭제는 앱 기능과 기기 설정으로 직접 수행할 수 있으며 방법에 관한 문의는 위 이메일로 받습니다.

6. Android 권한과 외부 구성요소

앱 소스의 Android Manifest에는 일반 권한 android.permission.INTERNET이 선언되어 있습니다. 이 권한은 네트워크 접근 가능성을 의미하지만 그 자체가 목록의 자동 업로드를 뜻하지는 않습니다. 현재 쇼핑 기능 코드에는 개발자 서버·분석 서버로 목록을 자동 전송하는 기능이 없습니다. 개인정보처리방침 같은 외부 링크를 열 때에는 네트워크 접속이 발생할 수 있습니다.

빌드된 APK에는 AndroidX의 비공개 동적 리시버 보호를 위한 앱 패키지별 DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION이 추가될 수 있습니다. 이는 앱 내부 수신자 보호용 권한이며 개인정보 수집을 위한 사용자 허용 권한이 아닙니다.

현재 구현은 위치·연락처·카메라·마이크·광고 식별자 접근 기능을 사용하지 않습니다. 파일 복원은 이용자가 선택한 파일을 읽으며, 전체 사진·파일을 자동 수집하는 기능은 없습니다.

주요 실행 구성요소는 Vue 3, Capacitor Core/Android, Capacitor Preferences(로컬 저장), Filesystem(백업 파일 생성), Share(Android 공유창), AndroidX 및 운영체제 WebView입니다. Vite와 Capacitor CLI는 빌드 도구입니다. 현재 소스와 의존성 설정에는 광고·사용자 행동 분석·원격 오류 수집용 SDK(Firebase Analytics/Crashlytics, AdMob, Sentry 등)를 도입하지 않았습니다. Google Services 설정 파일도 포함되어 있지 않습니다.

디버그 시험판에서는 기기 디버깅 로그에 플러그인 호출 정보나 목록 내용이 표시될 수 있습니다. 이는 원격 수집 SDK가 아니며 개발자에게 자동 전송되지 않습니다. 로그를 다른 사람에게 보낼 때 개인정보 포함 여부를 확인하세요.

7. 개인정보처리방침 웹페이지 접속

이 페이지는 GitHub Pages의 정적 HTML로 제공합니다. 자체 분석 도구, 광고, 외부 폰트, 쿠키 설정 스크립트 또는 목록을 받는 입력 폼을 넣지 않습니다. 방침 링크로 쇼핑 목록을 URL·쿼리나 요청 본문에 첨부하지 않습니다.

다만 GitHub는 Pages 제공 및 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 앱에서 이 페이지를 열거나 이메일·외부 정책 링크를 이용하면 해당 제공자의 네트워크 및 개인정보 처리 정책이 적용됩니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요.

8. 방침 변경

실제 앱의 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신하고 앱 설정의 링크를 통해 확인할 수 있도록 합니다. 새로운 서버·계정·분석 SDK 등 개인정보 처리에 중요한 변경을 도입할 경우 변경 내용과 필요한 안내를 제공합니다.
